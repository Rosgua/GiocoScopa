# Gioco della Scopa in Python
## Descrizione
Progetto sviluppato in Python che implementa il gioco della Scopa utilizzando i principi della programmazione 
a oggetti (OOP).  
L'applicazione gestisce la logica di gioco, il mazzo di carte, i giocatori e l'interfaccia utente in modo modulare.

##  Obiettivi del progetto
- Applicare i principi di Object-Oriented Programming
- Implementare la logica completa del gioco della Scopa
- Strutturare il codice in moduli riutilizzabili
- Migliorare la gestione dello stato di gioco

##  Tecnologie utilizzate
- Python
- Programmazione a oggetti (OOP)
- Visual Studio Code
- Anaconda
- Streamlit

##  Come eseguire il progetto
1. Clona il repository:
git clone https://github.com/Rosgua/GiocoScopa.git
2. Entra nella cartella:
   cd GiocoScopa
3. esegui il programma:
   python gs.py
